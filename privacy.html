プライバシーポリシー

Moonstep English（以下「本アプリ」。iPhoneアプリ版とWeb版を含みます）は、無料・広告なしの英会話学習アプリです。本アプリは、利用者の個人情報を収集しません。

1. 収集する情報

本アプリは、アカウント登録、氏名・メールアドレスの入力、広告、アクセス解析、トラッキングを一切行いません。

2. 端末内だけに保存する情報

学習の記録（進み具合、復習の予定、設定、呼び名など）は、ご利用の端末の中だけに保存します。運営者のサーバーに送られることはありません。アプリを削除するか、設定画面の「学習記録を消す」で消去できます。

3. マイクと音声認識

  • マイクは、発音の録音と聞き返し、発音チェックのために、利用者が操作したときだけ使います。録音した音声は端末の中で再生するだけで、保存・送信しません。
  • 発音チェックでは、端末（iOS／ブラウザ）が提供する音声認識機能を使います。音声認識の処理のため、音声がAppleなどOSの提供元に送られる場合があります。その取り扱いは各提供元のプライバシーポリシーに従います。

4. 英語音声ファイルの取得

模範音声のファイルは GitHub Pages から取得し、端末に保存して再利用します。取得の際、通信の仕組み上、IPアドレスなどの接続情報が GitHub 社のサーバーに記録される場合があります。

5. App Store の評価依頼

iPhoneアプリ版では、Apple 公式の仕組み（StoreKit）で評価をお願いする画面を表示することがあります。表示するかどうかと回数は iOS が管理し、評価の内容を本アプリが受け取ることはありません。

6. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub のリポジトリからお寄せください。
